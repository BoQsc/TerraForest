# TerraForest generated-artifact backup

Status: inventory and upload in progress. Do not treat this as a complete backup yet.

This branch preserves project-only generated evidence separately from normal source work. Large lossless deduplicated volumes will be attached to a dedicated draft backup release, with a catalog mapping each original path to its full SHA-256. This is archival evidence, not a gameplay release or an FPS qualification.

Private Codex conversations, account credentials, rebuildable compiler/import caches and unmatched player saves are excluded and remain local. Existing licenses, authorship and provenance are unchanged; see the project contribution and license inventory files.

The initial verified local retention reclaimed 8.372 GiB net while preserving 99 test worlds and 11 frozen builds. Both a complete world and a complete build passed restore verification.
