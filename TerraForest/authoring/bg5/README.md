# BG5 editable masters

These five supplied GLBs are preserved byte-for-byte, including named parts,
animations and embedded metadata. Their hashes and the contributor's explicit
CC0 confirmation are recorded in `provenance.json`. Do not edit these files as a
side effect of generating game assets. Replace an authoring version deliberately
and update its provenance/hash before rebuilding.

The contributor reports creating all model, texture and reference inputs using
their own/generated material through the ChatGPT website (Pro plan). On
2026-10-30 they confirmed: “All inputs were mine/generated by me; CC0 approved.”
The supplied assets and their runtime derivatives are dedicated under
[CC0-1.0](https://creativecommons.org/publicdomain/zero/1.0/).
This records the contributor's grant and source statement; existing embedded
reference filenames/reconstruction notes are retained.

`runtime_recipe.json` describes the conversion and canonical sizes. The folder
is excluded from Godot imports and game exports. Editable masters remain in the
repository/source archive. See `docs/BG5_RUNTIME_ASSETS.md` for the workflow.
