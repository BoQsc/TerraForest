Small exploration locations, revision 1, 2026-11-01.
Original TerraForest contributor work, AI-assisted with OpenAI Codex.
No external models, diagrams, snippets or copied layouts were used.
User request: compact branching caves and mines, structures, supply crates,
seated/lying sleeper encounters, not a straight tunnel template.

Original layout data: small_locations.poi.json, dedicated CC0-1.0 under the
repository contribution policy. Layout coordinates, view anchors, timber frame
locations and supply/encounter anchors are original authoring data.
The 2026-11-01 portal revision adds bounded rectangular entrance recesses to
remove thin exposed roof remnants. These original cuts remain editable terrain;
no texture repaint, imported geometry or global lighting change masks the defect.
Code: cave_layouts.gd, generation.gd and associated native/test/authoring code
are 0BSD. The catalog/native planning boundary is described in
docs/GAMEPLAY_EXPANSION.md; layouts are not monolithic imported meshes.
Existing TerraForest timber block materials and wooden chest models retain
their existing provenance and terms; this set does not relicense them.

Watchtower W1: watchtower_w1.tres is original CC0-1.0 authoring data,
baked from the new 0BSD watchtower.gd recipe. Its footing, posts, stair flights,
landings, guards, roof slopes and joints are individual native grid cells, not
an imported or monolithic model. The storage attachment uses the unchanged
existing wooden chest. Original authorship, AI assistance and contribution
terms above apply; no new third-party assets were introduced. The original
0BSD watchtower_sites.gd uses the shared native lot planner for new-world sites;
generation.gd publishes its native blocks, upper-floor supplies and sleeper.

Layout art and natural-site fit require review. Test success is not visual
acceptance or approval of any existing building replacement.
