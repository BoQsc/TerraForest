# Ranger assault rifle authoring

Original CC0 geometry and flat PBR materials, generated by the 0BSD
`tools/author_ranger_rifle.py`. Blender 5.2.3 LTS was used as an external authoring
tool. `Ranger.blend` contains only the new body and magazine; runtime GLBs are
separate rigid pieces. No character rig, mesh or texture is embedded in them.

Reproduce from the TerraForest project folder:

```powershell
& 'C:/Program Files (x86)/Steam/steamapps/common/Blender/blender.exe' --background --factory-startup --python-exit-code 1 --python tools/author_ranger_rifle.py
```

The existing `Weapon_Carbine` and `Weapon_Magazine` anchors determine presentation
fit. `human_view.gd` attaches each new part with inverse rest-bone compensation;
the magazine therefore follows the existing reload hand trajectory. Original
carry/equip/holster/reload actions retain their timing. Fire/HipFire actions are
retimed to 80 ms and a camera-relative offset aligns first-person iron sights.

`Ranger.json` records authoring version and GLB hashes. Exact asset scope and
dedication are in `../runtime/assets/Ranger.LICENSE.txt`. Existing character and
animation provenance remains in `../LICENSE.txt` and the repository inventory.
