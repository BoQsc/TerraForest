## Exact scope and origin

- `301.res`, `302.res`, `303.res`: original hood, vest and paired footwrap meshes,
  embedded original mathematical weave textures and named-bone weight palettes.
- `301.glb`, `302.glb`, `303.glb`: portable, unrigged exports of those same original
  meshes and embedded materials. These files contain no character body or rig.
- `301__albedo.png`, `301__albedo2.png`, `302__albedo.png`, `302__albedo2.png`,
  `303__albedo.png`, `303__albedo2.png`: Godot's extracted copies of the original
  embedded weave patterns. Associated `.import` files are generated import metadata.
- `manifest.json`: version, prompt, tool version, recipe and output SHA-256 hashes.
- `derivatives.json`: hashes and scopes of the extracted textures, ground models
  and shared icon atlas at the verified bake.
- `../../../player_runtime/art/drops/301.res`, `302.res`, `303.res`: normalized
  dropped-item derivatives generated by `tests/bake_item_icons.gd`.
- Clothing tiles `301`, `302`, `303` in
  `../../../player_runtime/art/item_icons.trtex`: rendered derivatives. The rest
  of that shared atlas retains its own provenance; this notice does not relicense it.

All geometry is independently constructed from mathematical rings, panels,
bindings and boxes in `tools/author_woven_clothes.gd`. Fabric pixels are generated
from a small periodic weave formula. No garment models, textures, reference images,
motion capture or third-party code were imported or traced. The original request
was to author/add wearable 3D clothing for the existing character view.

The existing R11 body was inspected for fit and named-bone compatibility within
its existing runtime use. No R11 vertices, textures, animation tracks or skeleton
are included in these garment exports. The existing character and screenshots
showing it retain the inherited provenance in `addons/characters/LICENSE.txt` and
GAP-002 in the license inventory; this notice does not resolve that record.

Godot 4.7.2 and OpenAI Codex were external authoring tools. They are not distributed
as part of this asset pack. Newly authored generator, adapter and verification
scripts are separately marked 0BSD. Reproduction instructions are in README.md.
