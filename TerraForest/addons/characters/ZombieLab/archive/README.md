# Preserved history

This directory is excluded from Godot imports.

- `r3/`: deprecated F3/R3 GLB, matching editable Blend and contract. No active F3 button or hotkey loads it.
- `r4.previous/`: exact R4 GLB and Blend from before the attack/traversal expansion.
- `selector.previous/`: prior revision-selector manifest and tests/reports. These describe the previous build and do not validate the current behavior expansion.

The current model and controller are identified by `../assets/zombie.revisions.json`. F1 and F2 stay in the active assets/source folders as preserved original options.
