# Homestead Manor — original building dedication

TerraForest contributors dedicate the original room plan, cell arrangement,
furnishing arrangement and `homestead_manor.tres` under **CC0-1.0**. New code in
this folder is **0BSD**. Authored with Codex and the existing external Godot
4.7.2 Steam installation on 2026-11-26; no external architectural model, drawing
or image was copied.

Brief: a very large mansion with matching rooms for all ten Homestead furnishing
packs, a new courtyard design, useful circulation, outdoor objects and measurable
native object handling. The source reuses the repository's existing cell/window/
door builder and thin roof assembly routines. Existing building materials, the
BG5 windows/doors, and Homestead/Outdoor models retain their own asset notices;
this dedication covers the new building arrangement, not a relicensing of inputs.

`provenance.json` records source hashes and the exact baked prefab. The source
can be rebaked through the admitted `homestead_mansion` test with
`-- --author-mansion`. The regular test checks placement, local removal,
restoration, stairs and rendered room views. This is an additional design for
review, not a replacement of an approved house or a generation default.
