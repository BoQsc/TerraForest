# Original grand building arrangements

TerraForest contributors dedicate the original floor plans, cell arrangements,
furnishing arrangements and the three adjacent baked `.tres` prefabs under
**CC0-1.0**. New scripts, tests and tooling are **0BSD**. Authored with Codex
from the user's three-building brief, using the existing external Godot authoring
tool and existing repository construction cells, Homestead furniture, doors,
windows and E2 building finishes. No external model, texture or reference was imported.

This dedication covers the new arrangement data. Existing code, models, textures,
their provenance and retained notices keep their original terms. Exact source,
baked-data and inherited-input hashes are in `provenance.json`; the corresponding
asset folders retain the notices for those inputs. The repository license
inventory remains authoritative for existing exceptions.
