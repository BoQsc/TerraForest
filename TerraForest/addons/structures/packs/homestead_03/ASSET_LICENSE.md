Covered assets: `pack.json`, `models/bathtub.tres`, `models/toilet.tres`,
`models/mirror.tres`, `models/towel_rail.tres`, `models/towels.tres`,
`models/soap_dish.tres`, `models/paper_holder.tres`, `models/laundry_tub.tres`,
`models/washboard.tres`, `models/broom_set.tres`, their embedded materials and
textures, and `icons.trtex`.

These original parametric models were authored with Codex for TerraForest on
2026-11-26. The user requested a separate Homestead 03 pack using the proposed
washroom/utility roster, followed by a picture of the actual new objects.
The brief specifies cream enamel, dull zinc, faded teal towels and weathered
timber. No external models, photographs, images, textures or branding were
supplied or copied. The inexpensive mirror surface contains no captured room
image or third-party reflection photograph.

Editable geometry is in `author.gd`. It reuses this project's original 0BSD
mesh helpers and CC0 procedural material patterns from Homestead 02; those
existing terms and provenance remain intact. The runtime meshes contain their
own embedded geometry, materials and textures. `provenance.json` records exact
asset hashes and both the local author and reused helper source hashes.

Godot's primitives and SurfaceTool are external authoring tools, not new
vendored dependencies or assets covered by this dedication. Original authoring,
catalog, integration and test code is **0BSD**. License dedication remains
separate from visual review and performance acceptance.
