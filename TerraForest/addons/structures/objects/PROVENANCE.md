# Door definition provenance

`wooden_door.object.json` and `../../../mods/example_doors/example.objects.json`
are original TerraForest authoring data, created with OpenAI Codex assistance
on 2026-10-30, dedicated under CC0-1.0. Task: readable door definitions, GLB
visual replacements, and a second door supplied by a mod without changing
gameplay code. No external reference assets or new GLB artwork were used.

The built-in definition transcribes the existing door's identity, dimensions,
recipe, salvage and durability. The example reuses the existing door mesh at
0.8 width; it adds no art. Existing mesh/texture notices remain in force.
Future supplied models require their own source, creator and license evidence
under CONTRIBUTING.md; this notice does not cover them.
