Covered files: `aged_brick.trtex`, `weathered_plaster.trtex`,
`coursed_limestone.trtex`, `weathered_timber.trtex`, `slate.trtex`,
`patinated_zinc.trtex`, `aged_terracotta.trtex`, `soot_stone_trim.trtex`.
They are opaque RGB PNG data loaded through the native shared texture array.

Each material was generated separately with the built-in OpenAI image generation
tool for this project on 2026-10-30; timber received a layout correction on
2026-10-31. No downloaded material, external image, branding or third-party
reference was supplied. The existing project's material set was visually
inspected to describe its general dark, weathered character in original prompts.
The timber edit used only this contribution's first generated timber image.
The authoring service is an external tool; its software is not distributed here.

The adjacent `provenance.json` identifies exact source/output hashes, prompts,
dimensions and technical preparation. Full generated masters, the rejected timber
variant, the edit prompt and the 1024 comparison tiles are retained under
`reviews/building_expansion/materials_v2/` in the source checkout, outside game
exports. Godot performs only RGB conversion and Lanczos resizing for runtime use.
The rejected procedural E1 set and its original provenance remain archived.

The dedication is separate from visual acceptance. E2 is a review candidate;
existing approved textures and legacy saved material identities are unchanged.
