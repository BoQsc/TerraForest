# Explicit prefab attachment envelope — 2026-10-18

NativeBlockPrefab now exposes a serialized attachment_envelope AABB and configure_attachment_envelope(box). Empty AABB retains legacy block-only bounds; valid positive finite bounds within local[-4095,4096] merge with block bounds. Quarter-turn placement and native composition preserve the union. Definition revision changes invalidate pending placement. Foundation/site bounds and protected-actor transaction checks consume existing placement_bounds, so overhangs cannot bypass those checks. Model proxies must still fit inside the declared union; overlap checks, budgets and atomic publication remain.

Targeted checks pass: undeclared overhang rejects, declared model attachment places in four rotations, protected boxes positioned only within the overhang reject atomically, invalid envelopes preserve the prior definition, changing bounds cancels staged placement without mutation, composition retains rotated bounds, resource save/fresh load retains bounds, and empty reset restores legacy bounds. Existing furnished-cottage transaction checks also pass. Both native Windows debug/release binaries rebuilt with pinned Zig/prebuilt SDK. Tests ran against debug; no release-runtime or visual/large-scale qualification is claimed.

This is authoring support, not automatic bound inference or a new main-world prefab. Authors must declare a conservative envelope containing attachments. A broader envelope can enlarge foundation grading/protection regions; foundation_samples remain based on actual block columns. It does not supply structural support, terrain clearance sampling for arbitrary attachment geometry or bridge siting. Older binaries do not support the new resource property. Existing world-save schema is unchanged.

The initial build caught a missing composed-envelope declaration after a mixed-line-ending edit; corrected before testing. Reproduce with run_godot_check.py prefab_envelope (require PREFAB_ENVELOPE failures=0) and prefab_transaction (require failures=0), both --headless. Water untouched.
