# Weighted pickaxe - rejected and scrapped

On 2026-10-24 the user rejected this motion as unnatural, cartoonish and worse
than the current pickaxe, and asked to scrap it completely. They clarified that
they expected a substantially new animation, not a derivative of the existing
swing. This is a closed, rejected experiment, not a candidate awaiting approval.

The weighted Blender source, GLB, animation report, runtime AnimationLibrary,
authoring README, generation/import/preview/encoding scripts and dedicated test
(including Godot UID sidecars) were removed from the working asset/tool folders.
Temporary renders were removed as well. No default selector or gameplay code
was changed. The existing pullback and original R11 model are preserved.

The two videos and selected images here are retained solely as rejected visual
evidence. They must not be treated as accepted work or a motion source for a new
attempt. Historical import/test reports describe the discarded version. The
fifteen passing technical checks did not establish realistic movement or visual
quality; the user's rejection overrides the earlier pending-review status.

Pickaxe.current-vs-weighted.mp4 shows the current animation on the left and
the rejected copy on the right. Pickaxe.weighted-preview.mp4 shows only the
rejected copy. Both used the actual Godot rig in a scripted studio, with two
normal-speed solid swings, one half-speed solid swing, and normal/half-speed
misses. They were never evidence of live collision routing or mining.

baseline_preserved.json and baseline_verification.json record the unchanged
eleven source/runtime files. rejection.json records the disposition and removed
file list. Any future replacement needs fresh motion blocking, a new comparison
and explicit user acceptance before it can become the default.
