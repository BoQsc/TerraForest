# Unified production generation

2026-10-23. This is workflow/integrity evidence, not acceptance of the entire
world rewrite, world design, laptop thermals or sustained 60 FPS performance.

Ordinary creation previously booted rendered developer qualification twice,
including fixed camera delays and walking checks. It now uses one generation
scene, native saved-data verification and root-last publication. Native terrain
earthworks and atomic prefab placement happen before rendering/collision loading.
That scene captures loading photographs and caches all map layers. GDScript
coordinates jobs/UI; native codecs own the integrity and data operations.

The updated library/create/generation screens were inspected at 1920×1080. The
generation screen uses a real view once one exists, reports its stage and allows
cancellation. Legacy review generators are available only with --developer-worlds;
existing saves remain openable. Developer rendered qualification remains explicit.

These are different warmed/cold executions and settings, not controlled relative
performance measurements. A discarded pacing-only water change observed 38.0 s
overall but did not materially improve lake creation; it was removed. No water
source/DLL change is included. Generated lake authoring still takes 15–29 s; first
photograph residency takes roughly 12–37 s in these runs. Those costs remain open.

For seed 1703/gen 19, terrain, structures, generated locations and water sections
retain the exact prior authoritative digests. See section_digests in the retained
native verification. Player presentation/pose can differ after photo capture.
Every normal source/bundled creation used one child and successful native binary
verification. It does not replace separate world traversal/visual qualification.

Fresh playback originally failed its stronger cache test: terrain/water hit but
blocks/models rebuilt. That failure is retained (105909738862Z). Native checkpoint
certificates now bind derived rasters to the exact ordinary paged startup identity;
all four layers hit cache with zero terrain patches. Edit invalidation/paging
identity checks also pass. Canonical root bytes remained unchanged during reopen.

Native verification rejects changed world identity and damaged terrain/building/
water inner sections with a valid outer checksum. Failed verification releases
its lease, restored disposable fixtures verify again, and the source root stays
unchanged. Existing terrain-region corruption tests check referenced dependencies.
Cancellation and failure/recovery checks pass without exposing a partial world.

The final export is 194,077,000 bytes with 14 external native libraries. The pack
starts and reopens the world generated by the explicit-PCK coordinator. Both its
coordinator and generation child propagate --main-pack. This is editor-executable
plus PCK qualification on the current machine, not clean-machine release proof.
Automatic Blender authoring imports are disabled; existing runtime glTF is used.

  initialized standard hash without calling update on zero bytes.
- 105909738862Z: real building/object map cache mismatch; corrected as above.
- 104809799738Z: all 87 archive assertions passed but launcher expected the wrong
  completion token. Correct-token rerun 110623777006Z passed; retain both.
- Discarded ordinary-water batch/pacing attempts had no demonstrated material
  improvement and were fully reverted.
- Repetitive cottage/office groups, exposed shoulders and landscape integration
  remain visually rejected. The retained images establish UI/data continuity only.
- Native selective terrain residency/full-history capacity, retention-aware GC,
  failed mining-arrival latency, lake pending shutdown/ID persistence, complete
  options/POI/map coverage, compute qualification, vegetation arrival cases and
  representative populated runtime/thermal evidence remain open.

The next generator change must remove gameplay frame pacing from offline data
authoring using the same native static volume algorithm, preserve exact geometry
and saved quantities, support bounded cancellation and pass actual fresh reopen.
