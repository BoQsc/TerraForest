# Baked entrance approaches

14 outer-district buildings receive 1.5 m wide paved approaches from the end of
their stair footprint to the facing street. This is optional site-plan metadata,
using existing native terrain grading, persistence and pavement vegetation masks.
No additional runtime nodes, collision objects or update loop.

Four layouts and four rotations pass count, grading and bounds checks. Full world
bake/save/fresh-process reopen passed. A 25.35 s saved-world view was inspected:
the southern cottage has a visible approach meeting the foot of the stairs.
This is visual validation, not a new player traversal or performance qualification.
Central buildings and the separate cellar cottage retain their existing approaches.

Review launcher v3 opens a separate save; v1 and v2 remain selectable and unchanged.
