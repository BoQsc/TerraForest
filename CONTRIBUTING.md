# Contributing to TerraForest

TerraForest is public-domain-first: **0BSD for new original code and CC0-1.0 for
new original assets**, with existing grants and exceptions preserved.

Read the [full contribution and intake policy](TerraForest/CONTRIBUTING.md) before
submitting changes. Its canonical copy lives inside the project so it is also
included in standalone source archives. See the
[exception and provenance inventory](TerraForest/docs/LICENSE_INVENTORY.md).
